       title.
     - "Back" returns focus to the reason chosen before.
     - Confirming or undoing moves focus to the page heading, not onto the Undo
       button, to avoid a mis-tap.

       the change appears.

     focus goes to "Skip next order", not back to "Cancel subscription". That
     keeps one shared code path for skipping, which R5 asks for.
  5. Offers that can't apply are hidden. The skip offers are hidden when there
     is no next order date. A quantity offer is hidden when the lower amount
     isn't one of the choices, for example when the server says 12.
  6. The local cancel is its own field, not part of 003's plan-change state as
     003's plan suggested. That way "Discard changes" can never undo a cancel.
