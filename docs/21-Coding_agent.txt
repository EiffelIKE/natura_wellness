● Confirmed, it's a race in the test. When the skip goes well, `skip.kind`
  becomes `"closed"` and React unmounts the dialog content, alert included,
  while the `<dialog>` is still in the DOM. The sequence is this: `isHidden()`
  returns `false` (the dialog is still visible), the skip finishes, the alert
  unmounts and `alert.textContent()` keeps waiting for an element that no
  longer exists. The fix is to use `allTextContents()`, which doesn't wait and
  returns `[]`, so that `poll` evaluates again and sees `"skipped"`.
